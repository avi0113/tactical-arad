# ערד · ניהול משימות מבצעיות

תצוגה מקומית בלבד. אין שרת, אין מאגר נתונים, אין שמירה ואין חיבור לרשת.

המסכים מציגים דוגמה קבועה: מאגר משימות מוכנות מראש, ושלושה אירועים. לכל אירוע יש רשימת פעולות. חלק מהפעולות הן עותק עם נוסח שונה מהמשימה במאגר, כדי להראות שהרשימה של האירוע עומדת בפני עצמה.

## פתיחה

פותחים את הקובץ `index.html` בדפדפן, בלחיצה כפולה. אין צורך בהתקנה, בשרת או בחיבור לאינטרנט.

הניווט נשאר בתוך אותו קובץ: לוח בקרה, אירועים, ומאגר המשימות.

## בדיקה

```bash
npm test
```

הבדיקה רצה ב־Node על הקבצים המקומיים. היא לא מפעילה שרת ולא מתחברת לרשת. אם מופיע `# fail 0`, הבדיקה עברה.
